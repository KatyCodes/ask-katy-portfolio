# Content Intake and Approval

The assistant may use only facts explicitly approved for public recruiter-facing answers. Uploading a source does not automatically approve every detail in it.

## Useful source material

- Current résumé in DOCX or PDF
- LinkedIn profile export or copied profile text
- Portfolio and GitHub project descriptions
- Work samples that contain no confidential employer or customer information
- Accomplishment notes with metrics and necessary qualifiers
- Training, documentation, support, integration, and cross-functional examples
- The complete job posting and application deadline

## Fact review fields

Each extracted fact will be reviewed with:

- Stable fact ID
- Public statement
- Supporting source
- Topics and relevant roles
- Metric, baseline, and qualifier when applicable
- Public or excluded status
- Katy's approval date

## Never include

- Credentials, tokens, private URLs, addresses, or sensitive contact data
- Confidential employer, customer, financial, or security information
- Unverified technologies, certifications, titles, metrics, or responsibilities
- Personal details that are irrelevant to the application
- Other real job applications in the same employer context

## Demo application content still needed

- Final role title and complete posting text or URL
- Final personalized opening paragraph
- Confirmation of the three featured accomplishments
- Approved answer set and tone
- Desired résumé link and contact links
- Optional expiration or revocation date for the application URL
